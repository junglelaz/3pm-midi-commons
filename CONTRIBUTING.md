# Contributing to 3PM MIDI Commons

Help musicians make musical choices: useful patterns, space for interpretation,
and clear descriptions are more valuable than a larger file count.

For a musical contribution, include the key, tempo, meter, bar count, intended
instrument and a note about how it layers. Explain whether AI tools were used
and which edits you made. Do not submit copied songs, commercial samples,
confidential projects or material you cannot authorize for this collection.

Contributed MIDI/note data must be offered under CC0 1.0; contributed software
must be offered under MIT. Do not submit someone else's work without the
necessary permission. A contributor's name can be listed when requested.

Keep every note-off inside the loop boundary, preserve intentional rests,
avoid ambiguous overlapping same-pitch notes on one channel, and verify tempo,
key and time-signature metadata. Distinguish transpositions from new patterns.
Test both individual parts and any claimed layering relationship.

Useful code contributions include better preview synthesis, screen-reader
support, smaller data payloads and additional meaningful validation. Never add
telemetry, remote dependencies or account requirements without a clear decision
and public documentation.
